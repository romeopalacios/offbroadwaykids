# Off Broadway Kids Redesign

Static HTML/CSS/JS redesign ready to open in VS Code.

## Files
- `index.html` — redesigned homepage
- `team.html` — redesigned team page
- `programs.html` — redesigned current program listings page
- `css/styles.css` — responsive desktop/mobile design system
- `js/main.js` — mobile menu, reveal animations, sticky header, gallery lightbox

## Run locally
Open the folder in VS Code and use Live Server, or open `index.html` directly.

## Deploy
This project is static and can be deployed directly to GitHub Pages or Netlify.

## Important
The source site's existing photography is preserved via its current Squarespace CDN URLs so the original imagery stays intact. Before fully replacing the production site, download/export the original images into `assets/images/` and swap the `src` values to local paths if you want the new site to be completely independent of Squarespace.

The contact/newsletter forms are presentation-ready but need to be connected to the owner's preferred backend/form service before going live.
